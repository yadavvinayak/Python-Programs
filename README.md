## Python Programs in the Repository Root

The root directory also contains standalone programs covering fundamental Python concepts, including:

- Variables, data types, and type conversion
- Operators, conditional statements, and `match` statements
- Loops and number-based problems
- Strings, lists, tuples, and dictionaries
- Sets and collection operations
- Functions and basic algorithms
- Searching, sorting, and mathematical problems
- Patterns, matrices, and data structures
- File handling and other programming exercises

These examples are kept as individual `.py` files for easy reference and practice.

## How to Run

Python 3 is required.

Run a program from the repository root:

```bash
python "path/to/program.py"
```

For example:

```bash
python "Programs/your_program.py"
```

Replace the example path with the actual path of the program you want to execute.

Some programs may require input from the terminal or additional Python packages.
