# Python Programming Practice

This archive contains standalone `.py` examples grouped by topic. Most scripts can be run with Python 3:

```bash
python path/to/program.py
```

Many files include a small `if __name__ == "__main__":` demonstration. Functions are kept small so they can be imported and tested.

## Folders
- `Basic_Python_Programs`
- `Array_List_Programs`
- `Matrix_Programs`
- `String_Programs`
- `Dictionary_Programs`
- `Tuple_Programs`
- `Searching_Sorting_Programs`
- `Pattern_Programs`
- `Date_Time_Programs`
- `Regex_Programs`
- `File_Handling_Programs`
- `More_Python_Programs`

## Notes
- The scripts are independently written practice examples based on the requested topic list; they are not copied from another repository.
- File-handling scripts may read or write files you specify. Test them with sample files first.
- `execute_string_of_code.py` demonstrates `exec`; only use it with trusted source code.
- Some algorithms (for example BogoSort and Stooge Sort) are included for learning, not practical use.
- The list in the request included a few vague or underspecified problem titles; those are implemented as reasonable examples and may be adapted.
